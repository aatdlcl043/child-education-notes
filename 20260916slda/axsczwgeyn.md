# 载誉而归 | 郭颖医生新加坡之行：以医学为桥，促中新交流

> 更新时间：2026-09-16 (UTC+8)

近日，我院生殖与遗传科郭颖主任医师，受山东省非教育系统政府公派出国留学项目及医院资助，赴新加坡国立大学访学期间，作为中国访问学者优秀代表，受邀参加了由新加坡国立大学国际事务所组织的国立大学医院与中国驻新加坡大使馆的交流活动。

  使馆王磊公使衔参赞询问郭颖主任在新期间的访学成果与研究心得，肯定访问学者在促进中新两国医疗科技交流中发挥的桥梁作用。郭颖主任汇报了在生殖医学前沿领域的研究进展，重点介绍了我院生殖与遗传科将中医药特色与现代辅助生殖技术（ART）相结合所取得的临床优势与创新成果。

活动中，她还陪同参观了新加坡国立大学医院生殖中心，并与国际生殖医学权威专家P C Wong教授就生殖医学发展前景进行了交流。

此次高层交流不仅增进了相互理解，也为两院未来在人才交流（生殖衰老）方面的未来发展奠定了坚实基础。
