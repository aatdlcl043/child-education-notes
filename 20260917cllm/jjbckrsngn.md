# 发福利啦！中国红十字基金会免费赠药已启动！

> 更新时间：2026-09-17 (UTC+8)

**项目介绍：**

为弘扬“人道、博爱、奉献”的红十字精神，结合中央十三五规划中提出的“帮扶存在特殊困难的计划生育家庭”政策的要求，中国红十字基金会“成长天使基金”在爱心企业长春金赛药业股份有限公司捐赠下，发起“关爱家庭生育健康”公益项目，旨在将通过全国权威合作医院向经济困难的失独、不孕不育等家庭，且符合应用辅助生殖技术治疗的适应症患者免费捐赠援助药品，从而协助帮扶存在特殊困难的计划生育家庭，注重家庭发展。

资助条件：

1. 资助对象：需要进行辅助生殖技术治疗、家庭经济困难的失独、不孕不育等中国籍患者（年龄小于35岁、低保家庭可优先进行资助）。

2. 医学条件：经主治医生进行医学评估，符合应用辅助生殖技术治疗、且对援助药品无禁忌的患者。

项目委托：

烟台毓璜顶医院 生殖医学中心

地点：烟台毓璜顶医院西区九楼生殖医学中心门诊

申请资助流程：

1. 提出申请：申请人到合作医院处领取项目宣传单及申请表，并准备相关身份及经济证明文件

2. 医学评估：在合作医院医生处进行医学评估，并填写医学评估表

3. 项目审核：申请人携带填写好的申请表及医学评估表到合作医院项目负责人处进行审核

4. 审核通过：通过审核的申请人可在合作医院免费领取援助药品，并在药品领取单上进行签字确认

5. 接受治疗：申请人按医院程序接受相关治疗

6. 反馈：合作医院按季度向中国红基会反馈药品资助使用情况

**申请资料清单：**

**1.申请人身份证复印件**

**2.结婚复印件**

**3.医学评估表签字原件**

**4.项目申请表签字原件**

**5.经济情况证明文件（可提供低保证或经济收入证明等**）

说明：

1.项目免费药品捐赠来源于社会爱心企业的无私捐赠，项目将遵照捐赠人的意愿，只能用于患者的治疗，务请珍惜！

2.因捐赠数量有限，提交申请后并不等于一定获得资助，申请人在提交上述申请后，将由合作医院按申请顺序进行综合评估后确定资助；不符合条件的申请人不能得到项目资助。

3.申请人必须如实提交所有材料，凡提供虚假材料或不如实提交所有材料者，将彻底失去受助资格。
