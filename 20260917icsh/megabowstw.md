# 科普宣教｜春天狂打喷嚏？别把过敏性鼻炎当感冒

> 更新时间：2026-09-17 (UTC+8)

**⬆点击蓝字  关注我们**

****

过敏性鼻炎也叫变应性鼻炎，是IgE介导的鼻黏膜慢性非感染性炎症，本病一年四季都可以发病，但以春季发病率最高，无法根治但可控制。

**一、典型症状（四大核心）**

• 鼻痒：常揉鼻子，可伴眼痒、咽痒、耳痒

• 阵发性喷嚏：一次数个到数十个，晨起/夜间/接触过敏原后发作

• 清水样鼻涕：量大、不停流

• 鼻塞：间歇/持续、单侧/双侧交替

• 其他：嗅觉减退、眼红眼肿、咳嗽、胸闷（警惕哮喘）

**二、常见病因**

• 遗传：过敏体质，父母有过敏史风险更高

• 环境（吸入性为主）：

  ◦ 常年性：尘螨、宠物皮屑、霉菌、蟑螂

  ◦ 季节性：花粉（树/草/蒿）

• 诱因：空气污染、冷空气、刺激性气味、情绪

**三、分 类**

• 常年性：全年发作，多室内过敏原

• 季节性：春秋花粉季发作

**四、规范治疗（阶梯式）**

1. 基础：避免过敏原

• 花粉季：戴口罩、关窗、回家洗鼻换衣

• 室内：除螨、不养宠物、除湿、勤洗床品

2. 药物（一线首选，遵医嘱）

• 鼻用糖皮质激素（如糠酸莫米松、丙酸氟替卡松）：最有效，控制四大症状，连续用1–2周达最佳效果

• 第二代口服抗组胺药（氯雷他定、西替利嗪）：快速止痒、止喷嚏、止涕，嗜睡少

• 鼻用抗组胺药（盐酸氮卓斯汀）：起效快，局部用更安全

• 生理盐水洗鼻：日常护理，冲过敏原、减轻炎症

• 短期用：鼻用减充血剂（如羟甲唑啉），连续不超7天，防药物性鼻炎

3. 免疫治疗（脱敏）

• 适合中重度、药物控制不佳者

• 皮下/舌下含服过敏原制剂，逐步诱导耐受，疗程3–5年

4. 手术

• 仅用于严重鼻塞、药物无效（如下鼻甲消融、鼻中隔矫正），不根治过敏

**五、常见并发症（别忽视）**

• 支气管哮喘（约40%患者合并，“一个气道，一种病”）

• 变应性鼻窦炎、分泌性中耳炎、过敏性咽喉炎

**六、日常护理与预防**

• 坚持生理盐水洗鼻（每日1–2次）

• 花粉季提前2–4周用鼻喷激素预防

• 保持室内湿度40%–60%，减少尘螨/霉菌

• 不滥用鼻减充血剂炎
